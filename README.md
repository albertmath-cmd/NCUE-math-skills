# 彰化師範大學數學系 課程技能樹

一份把「修課規劃」做成遊戲技能樹風格的互動網頁。以 114 學年度數學系開課清單為基礎，用點擊的方式追蹤已修課程，並疊加先修需求鎖定、系必修進度、以及「職業路線」解鎖系統。

🔗 **線上網址**：`https://你的帳號.github.io/repository名稱/`

## 功能

- **課程節點**：每個課程是一個可點擊的節點，依大一上～大四下分區塊呈現
  - 左鍵點擊：課程學分 +1
  - 右鍵點擊：課程學分 -1
  - 節點滑條填滿 = 該課程視為「修過」
- **先修需求鎖定**：有先修規定的課程會以虛線框呈現，未滿足需求前無法加點，並列出目前還差哪幾門課（打勾／空心圈區分已修 / 未修）
- **系必修進度條**：獨立追蹤系必修清單的學分加總，全數修完才算達標
- **職業路線系統**：目前規劃三條路線 —— 數學研究家、資料分析家、程式創造家
  - 每條路線都有必修（藍框）與選修（紫框）課程清單與學分門檻
  - 解鎖條件 = 系必修全部修完 **且** 該路線自己的必修 / 選修學分達標
  - 點擊職業卡片可在技能樹上標示出該路線所需的課程

## 檔案結構

這是單一 HTML 檔案（`index.html`），所有資料、樣式、互動邏輯都寫在同一份檔案裡，沒有外部後端，靜態託管即可運作（例如 GitHub Pages）。

## 資料維護

所有課程資料都寫在檔案內的 `DATA` 陣列中，格式如下：

```js
['課程名稱', 學分數, [ ['先修課程名稱', 先修所需學分], ... ] ]
```

- 沒有先修需求的課程，第三個欄位留空陣列 `[]`
- 課名務必跟其他地方使用的名稱**完全一致**（包含全形括號），否則先修檢查會抓不到對應的課程

### 系必修清單

在 `REQUIRED_COURSES` 陣列中，列出系必修的課程名稱（只看「是否修過」，不看學分加總門檻）。

### 職業路線

在 `PROFESSIONS` 陣列中設定，每條路線由多條「規則」組成：

```js
{ label: '必修', kind: 'required', min: 9, courses: [...] }
```

- `kind`: `'required'`（技能樹上顯示藍框）或 `'elective'`（顯示紫框）
- `min`: 該規則需要達成的學分加總門檻
- `courses`: 屬於這條規則的課程名稱清單

## 更新網站內容

1. 修改本機的 `index.html`
2. 回到 GitHub repository，點進 `index.html` → 右上角鉛筆圖示「Edit」
3. 貼上新內容 → Commit changes
4. GitHub Pages 會在數分鐘內自動重新部署，不需要重新設定

## 已知限制

- 目前沒有連接資料庫，重新整理頁面後，已點擊的紀錄不會保留
- 課程與先修資料是依 114 學年度課程手冊人工整理，如遇開課異動需手動更新
